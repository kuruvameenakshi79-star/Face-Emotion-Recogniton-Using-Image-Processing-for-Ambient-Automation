Face Emotion Recognition Using Image Processing for Ambient Automation
Project Overview
This project detects human facial emotions using image processing and machine learning techniques and uses the detected emotion to control an ambient automation system.

Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Haar Cascade

Key Features
- Real-time face detection
- Facial emotion recognition
- Image processing using OpenCV
- Integration with hardware for ambient automation
- Emotion-based automation

Project Contribution
An existing face emotion recognition implementation was used as a base and modified and integrated with hardware to develop the ambient automation system as part of my major project.
